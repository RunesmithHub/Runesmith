# Runesmith.Templates

Templates for building Runesmith plugins.

```bash
dotnet new install Runesmith.Templates
dotnet new runesmith-plugin --name MyPlugin --id publisher.myplugin
```

| Template | Short name | What it creates |
| --- | --- | --- |
| Runesmith plugin | `runesmith-plugin` | A plugin: its contracts and implementation projects, a `plugin.json` manifest, an icon and a sample command. |
