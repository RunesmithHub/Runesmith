A plugin can change what the editor shows and does beyond completion and hover: put icons in the gutter, hints inside lines, code lens
above lines and highlights on text; offer quick fixes and refactorings; rename symbols; format documents; find references and
implementations; list symbols; fold code; color tokens by meaning; grow the selection; show call and type hierarchies; and see keys before
the editor does. Each is an export of `Runesmith.Sdk`, found the same way as the other [language features](./api.mdx#languages), and each
answer is kept apart per plugin, so one plugin's failure does not affect another's. Language servers get the same features without code
of their own; see [From language servers and analyzers](#from-language-servers-and-analyzers).

## Decorations

Export an `IDecorationProvider` to decorate documents. The editor asks it when a document opens, a moment after typing stops, and when the
provider raises `Changed`. Between answers, the decorations follow the edits: a span moves with the text around it, and a decoration whose
text is deleted goes away. Each provider's answer replaces only its own decorations.

This provider flags every `TODO` with a gutter icon, a dotted underline and a mark beside the scroll bar:

```csharp title="TodoMarkers.cs"
using System.Composition;
using Runesmith.Sdk.Documents;
using Runesmith.Sdk.Languages;
using Runesmith.Text;

namespace TodoPlugin;

[Export(typeof(IDecorationProvider))]
[Languages(LanguagesAttribute.Any)]
[Shared]
public sealed class TodoMarkers : IDecorationProvider
{
    public Task<IReadOnlyList<Decoration>> GetDecorationsAsync(DecorationRequest request, CancellationToken cancellationToken)
    {
        var snapshot = request.Snapshot;
        var decorations = new List<Decoration>();
        for (var number = 0; number < snapshot.LineCount; number++)
        {
            var column = snapshot.GetLineText(number).IndexOf("TODO", StringComparison.Ordinal);
            if (column < 0)
                continue;

            var span = new TextSpan(snapshot.GetLine(number).Start + column, 4);
            decorations.Add(new GutterMarker(span, "flag") { Tone = DecorationTone.Warning, ToolTip = "Something **to do**", ShowsInOverviewRuler = true });
            decorations.Add(new TextHighlight(span) { Underline = UnderlineStyle.Dotted, Tone = DecorationTone.Warning });
        }

        return Task.FromResult<IReadOnlyList<Decoration>>(decorations);
    }
}
```

| Decoration | What it shows |
| --- | --- |
| `GutterMarker(span, icon)` | An icon from HammerUI's icon set beside the line where the span starts, in a `Tone`. `IsFilled` fills it with its tone, as for a breakpoint. `CommandId` and `CommandArgument` make it clickable; `ShowsInOverviewRuler` also marks the line beside the vertical scroll bar. |
| `InlayHint(offset, text)` | Faint text inside the line, such as `count:` or `: int`. `Side` says whether it belongs to the text after it (`Before`, the default) or before it (`After`), which decides where the caret at the offset is drawn. |
| `CodeLens(span, text)` | A line of small text above the line where the span starts. `CommandId` and `CommandArgument` make it clickable. Several on one line are shown side by side. |
| `TextHighlight(span)` | An `Underline` (`Solid`, `Dotted`, `Dashed` or `Wavy`, the default), a faint `Background`, or both, in a `Tone`. Its `ToolTip` shows in the hover. |

Every decoration has a `ToolTip`, as Markdown, shown when the pointer rests on it. The tones are the theme's colors: `Neutral`, `Accent`,
`Information`, `Success`, `Warning` and `Error`. Spans are in the coordinates of `request.Snapshot`, even when the user types while the
provider works: the editor moves the answer through the edits made since.

Raise `Changed`, from any thread, with a file path or null for every file, when the provider's decorations change for a reason other than
an edit, such as a test run finishing. Users turn inlay hints and code lens off with `editor.inlayHints` and `editor.codeLens`.

## Quick fixes and refactorings

Export an `ICodeActionProvider` to offer code actions. A `CodeActionRequest` has the document, its snapshot, the span (the selection, or the
caret's line), the problems that touch the span, and a `Trigger`:

| Trigger | When | Answer with |
| --- | --- | --- |
| `Automatic` | The caret stopped on a line, to decide whether the light bulb shows. | Only what is quick to find, such as fixes for the problems in the span. |
| `Invoked` | The user pressed <Keys>Alt+Enter</Keys> or clicked the light bulb. | Everything, including refactorings. |

A `CodeAction` has a title, a `Kind` (`QuickFix`, `Refactor` or `Source`), and an `Edit`, a command (`CommandId` and `CommandArgument`), or
both; the edit is applied first. `IsPreferred` puts an action at the top. To save work, leave `Edit` null and compute it in `ResolveAsync`,
which Runesmith calls when the user picks the action; keep what you need in `Data`.

```csharp title="UpperCaseAction.cs"
[Export(typeof(ICodeActionProvider))]
[Languages(LanguagesAttribute.Any)]
public sealed class UpperCaseAction : ICodeActionProvider
{
    public Task<IReadOnlyList<CodeAction>> GetCodeActionsAsync(CodeActionRequest request, CancellationToken cancellationToken)
    {
        if (request.Trigger == CodeActionTrigger.Automatic || request.Document.FilePath is not { } path || request.Span.IsEmpty)
            return Task.FromResult<IReadOnlyList<CodeAction>>([]);

        var text = request.Snapshot.GetText(request.Span);
        var change = new TextChange(request.Span, text.ToUpperInvariant());
        var edit = new WorkspaceEdit([new DocumentEdit(path, [change]) { Snapshot = request.Snapshot }]);
        return Task.FromResult<IReadOnlyList<CodeAction>>([new CodeAction("Convert to upper case", CodeActionKind.Refactor) { Edit = edit }]);
    }
}
```

### Workspace edits

A `WorkspaceEdit` is a list of `DocumentEdit`s, each a file's path and its `TextChange`s. The changes are in the coordinates of the file's
text as Runesmith reads it: the open document's text, or the file on disk with its line breaks as `\n`. Set `Snapshot` to the snapshot the
changes were computed for, and Runesmith refuses the edit when the document changed since, instead of changing the wrong text.

Runesmith checks every file before it changes any, opens the files that are not open in background tabs, and makes each file's changes
one step of that file's undo history. Import `IWorkspaceEditService` to apply an edit yourself, such as from a command.

## Rename

Export an `IRenameProvider`. `PrepareRenameAsync` returns a `RenameTarget`, the span of the name and the text the rename box starts with, or
null when the provider has nothing to rename there; `RenameAsync` returns the `WorkspaceEdit` that renames it. The first provider that
answers is used, so return null for documents or positions that are not yours. Throw `LanguageFeatureException` with a message for the user,
such as "Names defined in a library cannot be renamed", to stop with that message.

## Formatting

Export an `IDocumentFormattingProvider` for **Format Document** and format on save, and an `IRangeFormattingProvider` for **Format
Selection**. Each returns the changes that format the snapshot, an empty list when it is formatted already, or null when the provider does
not format that document. `FormattingOptions` has the editor's `TabSize` and `InsertSpaces`.

```csharp title="TrailingWhitespaceFormatter.cs"
[Export(typeof(IDocumentFormattingProvider))]
[Languages("markdown")]
public sealed class TrailingWhitespaceFormatter : IDocumentFormattingProvider
{
    public Task<IReadOnlyList<TextChange>?> FormatDocumentAsync(IDocument document, TextSnapshot snapshot, FormattingOptions options, CancellationToken cancellationToken)
    {
        var changes = new List<TextChange>();
        for (var number = 0; number < snapshot.LineCount; number++)
        {
            var text = snapshot.GetLineText(number);
            var kept = text.TrimEnd(' ', '\t').Length;
            if (kept < text.Length)
                changes.Add(new TextChange(new TextSpan(snapshot.GetLine(number).Start + kept, text.Length - kept), ""));
        }

        return Task.FromResult<IReadOnlyList<TextChange>?>(changes);
    }
}
```

The editor applies the changes as one undo step, and only when the text has not changed while the formatter ran. A formatter that runs a
program, such as a command-line formatter, starts it with `ILauncher` and needs the `process` capability.

## References and implementations

Export an `IReferenceProvider` for **Find References** (<Keys>Shift+F12</Keys>) and an `IImplementationProvider` for **Go to
Implementation** (<Keys>Ctrl+F12</Keys>). Each returns `DocumentLocation`s: a file, a start and, for the span of the name, an end. Every
provider of the language is asked and the answers are merged without duplicates. One place opens at once; several are listed in the
**References** panel. `includeDeclaration` says whether the symbol's own declaration belongs in the list.

```csharp title="IniReferences.cs"
[Export(typeof(IReferenceProvider))]
[Languages("ini")]
public sealed class IniReferences : IReferenceProvider
{
    public Task<IReadOnlyList<DocumentLocation>> GetReferencesAsync(IDocument document, TextSnapshot snapshot, int offset, bool includeDeclaration,
        CancellationToken cancellationToken)
    {
        var word = WordBoundaries.GetWordAt(snapshot, offset);
        if (word.IsEmpty || document.FilePath is not { } path)
            return Task.FromResult<IReadOnlyList<DocumentLocation>>([]);

        var name = Regex.Escape(snapshot.GetText(word));
        var found = Regex.Matches(snapshot.GetText(), $@"\b{name}\b")
            .Where(match => includeDeclaration || !IsKey(snapshot, match.Index))
            .Select(match => new DocumentLocation(path, snapshot.GetPosition(match.Index), snapshot.GetPosition(match.Index + match.Length)))
            .ToList();
        return Task.FromResult<IReadOnlyList<DocumentLocation>>(found);
    }

    // A key is declared where a line starts with it.
    internal static bool IsKey(TextSnapshot snapshot, int offset)
    {
        var line = snapshot.GetLineFromPosition(offset);
        return snapshot.GetText(TextSpan.FromBounds(line.Start, offset)).Trim().Length == 0;
    }
}
```

An implementation provider has the same shape. This one finds the keys a `.local.ini` file next to the document overrides:

```csharp title="IniImplementations.cs"
[Export(typeof(IImplementationProvider))]
[Languages("ini")]
public sealed class IniImplementations : IImplementationProvider
{
    public Task<IReadOnlyList<DocumentLocation>> GetImplementationsAsync(IDocument document, TextSnapshot snapshot, int offset, CancellationToken cancellationToken)
    {
        var word = snapshot.GetText(WordBoundaries.GetWordAt(snapshot, offset));
        var overrides = Path.ChangeExtension(document.FilePath, ".local.ini");
        if (word.Length == 0 || overrides is null || !File.Exists(overrides))
            return Task.FromResult<IReadOnlyList<DocumentLocation>>([]);

        var found = File.ReadAllLines(overrides).Select((text, line) => (text, line))
            .Where(entry => entry.text.TrimStart().StartsWith(word + "=", StringComparison.Ordinal))
            .Select(entry => new DocumentLocation(overrides, new TextPosition(entry.line, 0)))
            .ToList();
        return Task.FromResult<IReadOnlyList<DocumentLocation>>(found);
    }
}
```

## Occurrence highlights

Export an `IDocumentHighlightProvider` to highlight the other occurrences of the symbol under the caret. The editor asks a moment after the
caret stops on a word and draws each `DocumentHighlight` with a faint background: a `Write` in the information color, a `Read` or `Text`
in a neutral one. The first provider that answers is used; return null for documents that are not yours.

```csharp title="IniHighlights.cs"
[Export(typeof(IDocumentHighlightProvider))]
[Languages("ini")]
public sealed class IniHighlights : IDocumentHighlightProvider
{
    public Task<IReadOnlyList<DocumentHighlight>?> GetDocumentHighlightsAsync(IDocument document, TextSnapshot snapshot, int offset, CancellationToken cancellationToken)
    {
        var word = WordBoundaries.GetWordAt(snapshot, offset);
        if (word.IsEmpty)
            return Task.FromResult<IReadOnlyList<DocumentHighlight>?>([]);

        var name = Regex.Escape(snapshot.GetText(word));
        var highlights = Regex.Matches(snapshot.GetText(), $@"\b{name}\b")
            .Select(match => new DocumentHighlight(new TextSpan(match.Index, match.Length),
                IniReferences.IsKey(snapshot, match.Index) ? DocumentHighlightKind.Write : DocumentHighlightKind.Read))
            .ToList();
        return Task.FromResult<IReadOnlyList<DocumentHighlight>?>(highlights);
    }
}
```

## Symbols

Export an `IDocumentSymbolProvider` to list a document's symbols as a tree. The tree fills the **Outline** panel, the symbols around the
caret in the breadcrumbs under the tabs, and **Go to Symbol in File** (<Keys>Ctrl+R</Keys>). Each `DocumentSymbol` has a name, a
`SymbolKind`, the `Range` of the whole declaration, the `SelectionRange` that is selected when the user goes to it (usually the name),
an optional `Detail` shown after the name, `IsDeprecated`, and its `Children`. The first provider that answers is used. Runesmith asks
when the document opens and a moment after typing stops; raise `Changed` when the symbols change for another reason.

```csharp title="IniSymbols.cs"
[Export(typeof(IDocumentSymbolProvider))]
[Languages("ini")]
public sealed class IniSymbols : IDocumentSymbolProvider
{
    public Task<IReadOnlyList<DocumentSymbol>?> GetDocumentSymbolsAsync(IDocument document, TextSnapshot snapshot, CancellationToken cancellationToken)
    {
        var sections = new List<DocumentSymbol>();
        var keys = new List<DocumentSymbol>();
        for (var number = snapshot.LineCount - 1; number >= 0; number--)
        {
            var line = snapshot.GetLine(number);
            var text = snapshot.GetLineText(number);
            if (text.StartsWith('[') && text.IndexOf(']') is > 1 and var close)
            {
                var end = sections.Count > 0 ? sections[0].Range.Start - 1 : snapshot.Length;
                var name = new TextSpan(line.Start + 1, close - 1);
                sections.Insert(0, new DocumentSymbol(text[1..close], SymbolKind.Namespace, TextSpan.FromBounds(line.Start, Math.Max(line.End, end)), name)
                {
                    Children = [.. keys],
                });
                keys.Clear();
            }
            else if (text.IndexOf('=') is > 0 and var equals)
            {
                var key = text[..equals].Trim();
                var start = line.Start + text.IndexOf(key, StringComparison.Ordinal);
                keys.Insert(0, new DocumentSymbol(key, SymbolKind.Property, line.Span, new TextSpan(start, key.Length)) { Detail = text[(equals + 1)..].Trim() });
            }
        }

        return Task.FromResult<IReadOnlyList<DocumentSymbol>?>([.. keys, .. sections]);
    }
}
```

Export an `IWorkspaceSymbolProvider` to find symbols in the whole open folder by name, for **Go to Symbol in Workspace**
(<Keys>Ctrl+Shift+R</Keys>, or `#` in the search box) and **Search Everywhere**. Every provider is asked, whatever the language, so it needs
no `[Languages]`. The query may be fuzzy, such as `gUsr` for `GetUser`; return what could match and Runesmith ranks it.

```csharp title="IniWorkspaceSymbols.cs"
[Export(typeof(IWorkspaceSymbolProvider))]
[method: ImportingConstructor]
public sealed class IniWorkspaceSymbols(IWorkspace workspace) : IWorkspaceSymbolProvider
{
    public Task<IReadOnlyList<WorkspaceSymbol>> GetWorkspaceSymbolsAsync(string query, CancellationToken cancellationToken)
    {
        if (workspace.RootPath is not { } root)
            return Task.FromResult<IReadOnlyList<WorkspaceSymbol>>([]);

        var symbols = new List<WorkspaceSymbol>();
        foreach (var path in Directory.EnumerateFiles(root, "*.ini", SearchOption.AllDirectories))
        {
            var lines = File.ReadAllLines(path);
            for (var line = 0; line < lines.Length; line++)
            {
                if (lines[line].StartsWith('[') && lines[line].IndexOf(']') is > 1 and var close)
                    symbols.Add(new WorkspaceSymbol(lines[line][1..close], SymbolKind.Namespace, new DocumentLocation(path, new TextPosition(line, 1))));
            }
        }

        return Task.FromResult<IReadOnlyList<WorkspaceSymbol>>(symbols);
    }
}
```

## Folding

Export an `IFoldingRangeProvider` to say which lines fold. A `FoldingRange(StartLine, EndLine)` keeps its first line visible and hides the
lines after it up to and including `EndLine`; the folded line ends in `CollapsedText`, or an ellipsis. `Kind` is `Block` (the default),
`Comment`, `Imports` or `Region`. The first provider that answers is used; without one, the editor folds by indentation. Folded ranges stay
folded while the user types and when the provider answers again, matched by their first line.

```csharp title="IniFolding.cs"
[Export(typeof(IFoldingRangeProvider))]
[Languages("ini")]
public sealed class IniFolding : IFoldingRangeProvider
{
    public Task<IReadOnlyList<FoldingRange>?> GetFoldingRangesAsync(IDocument document, TextSnapshot snapshot, CancellationToken cancellationToken)
    {
        var ranges = new List<FoldingRange>();
        var section = -1;
        var comments = -1;
        for (var number = 0; number <= snapshot.LineCount; number++)
        {
            var text = number < snapshot.LineCount ? snapshot.GetLineText(number) : "[";
            var isComment = text.StartsWith(';');
            if (!isComment && comments >= 0 && number - 1 > comments)
                ranges.Add(new FoldingRange(comments, number - 1) { Kind = FoldingRangeKind.Comment, CollapsedText = "; ..." });
            comments = isComment ? (comments < 0 ? number : comments) : -1;

            if (text.StartsWith('['))
            {
                if (section >= 0 && number - 1 > section)
                    ranges.Add(new FoldingRange(section, number - 1));
                section = number;
            }
        }

        return Task.FromResult<IReadOnlyList<FoldingRange>?>(ranges);
    }
}
```

## Semantic tokens

Export an `ISemanticTokensProvider` to classify tokens by what they mean, such as a name that refers to a parameter. The editor draws them
over the TextMate highlighting. Each `SemanticToken` has a span within one line, a type from `SemanticTokenTypes` and
`SemanticTokenModifiers`. The first provider that answers is used. Runesmith asks for the tokens of the whole document when it opens and a
moment after typing stops; for a long document it first asks for the lines on screen with the overload that takes a span, which by default
filters the whole document's tokens. Until the answer comes, the tokens it has move with the edits, so colors do not flicker.

```csharp title="IniSemanticTokens.cs"
[Export(typeof(ISemanticTokensProvider))]
[Languages("ini")]
public sealed partial class IniSemanticTokens : ISemanticTokensProvider
{
    public Task<IReadOnlyList<SemanticToken>?> GetSemanticTokensAsync(IDocument document, TextSnapshot snapshot, CancellationToken cancellationToken)
    {
        var tokens = Reference().Matches(snapshot.GetText())
            .Select(match => new SemanticToken(new TextSpan(match.Index + 2, match.Length - 3), SemanticTokenTypes.Variable, SemanticTokenModifiers.Readonly))
            .ToList();
        return Task.FromResult<IReadOnlyList<SemanticToken>?>(tokens);
    }

    [GeneratedRegex(@"\$\{\w+\}")]
    private static partial Regex Reference();
}
```

The syntax color scheme colors each token through TextMate scopes, tried in order; the first scope the scheme has a rule for gives the color
and the font style. A type the editor does not know keeps its TextMate color.

| Type | Scopes |
| --- | --- |
| `namespace` | `entity.name.namespace` |
| `type` | `entity.name.type`, `support.type` |
| `class` | `entity.name.type.class`, `entity.name.type` |
| `enum`, `interface`, `struct` | `entity.name.type.enum`, `entity.name.type.interface` or `entity.name.type.struct`, then `entity.name.type` |
| `typeParameter` | `entity.name.type.parameter`, `entity.name.type` |
| `parameter` | `variable.parameter` |
| `variable` | `variable.other.readwrite`, `variable` |
| `property` | `variable.other.property`, `variable` |
| `enumMember` | `variable.other.enummember`, `constant.other.enum` |
| `event` | `variable.other.event`, `variable.other.property` |
| `function` | `entity.name.function` |
| `method` | `entity.name.function.member`, `entity.name.function` |
| `macro` | `entity.name.function.preprocessor`, `entity.name.function` |
| `decorator` | `entity.name.function.decorator`, `entity.name.function` |
| `label` | `entity.name.label` |
| `keyword`, `modifier`, `comment`, `string`, `number`, `regexp`, `operator` | `keyword`, `storage.modifier`, `comment`, `string`, `constant.numeric`, `string.regexp`, `keyword.operator` |

| Modifier | Effect |
| --- | --- |
| `Readonly` | A variable or parameter tries `variable.other.constant` first; a property tries `variable.other.constant.property`. |
| `DefaultLibrary` | A class, struct, interface, enum or type tries `support.class` and `support.type` first; a function or method tries `support.function`. |
| `Deprecated` | The token is struck through. |

The other modifiers do not change the color. Runesmith's own color schemes have rules for these scopes; a [color
scheme](./themes.mdx#syntax-color-schemes) of your own colors semantic tokens by adding rules for them.

## Selection ranges

Export an `ISelectionRangeProvider` for **Expand Selection** (<Keys>Shift+Alt+Right</Keys>) and **Shrink Selection**
(<Keys>Shift+Alt+Left</Keys>). Return the spans around an offset from the smallest to the largest, such as the word, its expression, its
statement and its block; each expand selects the next one that is larger than the selection. The first provider that answers is used;
without one, the selection grows through the word, the text inside each pair of brackets, the brackets, the line and the document.

```csharp title="IniSelectionRanges.cs"
[Export(typeof(ISelectionRangeProvider))]
[Languages("ini")]
public sealed class IniSelectionRanges : ISelectionRangeProvider
{
    public Task<IReadOnlyList<TextSpan>?> GetSelectionRangesAsync(IDocument document, TextSnapshot snapshot, int offset, CancellationToken cancellationToken)
    {
        var line = snapshot.GetLineFromPosition(offset);
        var text = snapshot.GetText(line.Span);
        var equals = text.IndexOf('=');
        var side = equals < 0 ? line.Span
            : offset - line.Start <= equals ? new TextSpan(line.Start, equals)
            : TextSpan.FromBounds(line.Start + equals + 1, line.End);
        TextSpan[] spans = [WordBoundaries.GetWordAt(snapshot, offset), side, line.Span, new TextSpan(0, snapshot.Length)];
        return Task.FromResult<IReadOnlyList<TextSpan>?>([.. spans.Where(span => !span.IsEmpty).Distinct()]);
    }
}
```

## Call and type hierarchies

Export an `ICallHierarchyProvider` for **Show Call Hierarchy** (<Keys>Ctrl+Alt+H</Keys>) and an `ITypeHierarchyProvider` for **Show Type
Hierarchy** (<Keys>Ctrl+Alt+Shift+H</Keys>). Both start with `Prepare...Async`, which returns the function or type at an offset as a
`HierarchyItem`: a name, a `SymbolKind`, the `Location` of the declaration, the `SelectionLocation` of its name, and `Data` you need later.
The first provider that prepares an item answers for it and for the items it returns, through `HierarchyItem.Provider`, which Runesmith
sets. The **Hierarchy** panel asks for each level when the user opens it.

A `HierarchyCall` is the other function and its `CallSites`: in the caller's file for incoming calls, and in the original function's file
for outgoing calls. This provider treats an INI file's `include=` lines as calls:

```csharp title="IniIncludes.cs"
[Export(typeof(ICallHierarchyProvider))]
[Languages("ini")]
public sealed class IniIncludes : ICallHierarchyProvider
{
    public Task<IReadOnlyList<HierarchyItem>> PrepareCallHierarchyAsync(IDocument document, TextSnapshot snapshot, int offset, CancellationToken cancellationToken)
    {
        if (document.FilePath is not { } path)
            return Task.FromResult<IReadOnlyList<HierarchyItem>>([]);

        var whole = new DocumentLocation(path, new TextPosition(0, 0), snapshot.GetPosition(snapshot.Length));
        return Task.FromResult<IReadOnlyList<HierarchyItem>>([new HierarchyItem(Path.GetFileName(path), SymbolKind.File, whole)]);
    }

    public Task<IReadOnlyList<HierarchyCall>> GetIncomingCallsAsync(HierarchyItem item, CancellationToken cancellationToken) =>
        Task.FromResult<IReadOnlyList<HierarchyCall>>([]);

    public Task<IReadOnlyList<HierarchyCall>> GetOutgoingCallsAsync(HierarchyItem item, CancellationToken cancellationToken)
    {
        var lines = File.ReadAllLines(item.Location.FilePath);
        var calls = new List<HierarchyCall>();
        for (var line = 0; line < lines.Length; line++)
        {
            if (!lines[line].StartsWith("include=", StringComparison.Ordinal))
                continue;

            var target = Path.Combine(Path.GetDirectoryName(item.Location.FilePath)!, lines[line]["include=".Length..].Trim());
            var site = new DocumentLocation(item.Location.FilePath, new TextPosition(line, 0), new TextPosition(line, lines[line].Length));
            calls.Add(new HierarchyCall(new HierarchyItem(Path.GetFileName(target), SymbolKind.File, new DocumentLocation(target, new TextPosition(0, 0))), [site]));
        }

        return Task.FromResult<IReadOnlyList<HierarchyCall>>(calls);
    }
}
```

A type hierarchy provider returns the types an item derives from in `GetSupertypesAsync` and those that derive from it in
`GetSubtypesAsync`:

```csharp title="IniSectionHierarchy.cs"
[Export(typeof(ITypeHierarchyProvider))]
[Languages("ini")]
public sealed class IniSectionHierarchy : ITypeHierarchyProvider
{
    public Task<IReadOnlyList<HierarchyItem>> PrepareTypeHierarchyAsync(IDocument document, TextSnapshot snapshot, int offset, CancellationToken cancellationToken)
    {
        var line = snapshot.GetLineFromPosition(offset);
        var text = snapshot.GetText(line.Span);
        if (document.FilePath is not { } path || !text.StartsWith('[') || text.IndexOf(']') is not (> 1 and var close))
            return Task.FromResult<IReadOnlyList<HierarchyItem>>([]);

        var location = new DocumentLocation(path, snapshot.GetPosition(line.Start), snapshot.GetPosition(line.End));
        return Task.FromResult<IReadOnlyList<HierarchyItem>>([new HierarchyItem(text[1..close], SymbolKind.Namespace, location) { Data = text[1..close] }]);
    }

    // A section named "a.b" derives from the section "a".
    public Task<IReadOnlyList<HierarchyItem>> GetSupertypesAsync(HierarchyItem item, CancellationToken cancellationToken)
    {
        var name = (string)item.Data!;
        var dot = name.LastIndexOf('.');
        return Task.FromResult<IReadOnlyList<HierarchyItem>>(dot < 0 ? [] : [item with { Name = name[..dot], Data = name[..dot], Provider = null }]);
    }

    public Task<IReadOnlyList<HierarchyItem>> GetSubtypesAsync(HierarchyItem item, CancellationToken cancellationToken) =>
        Task.FromResult<IReadOnlyList<HierarchyItem>>([]);
}
```

## Use the merged answers

Import `INavigationFeatures` or `ISyntaxFeatures` to ask every provider of a document's language the way the editor does, such as from a
command. `INavigationFeatures` merges references, implementations and workspace symbols and picks the first answer for occurrences,
symbols and hierarchies; `ISyntaxFeatures` does the same for folding ranges, selection ranges and semantic tokens. A provider that throws is
logged to the **Language features** channel and left out.

```csharp title="CountReferences.cs"
[Export(typeof(ICommandContributor))]
[method: ImportingConstructor]
public sealed class CountReferences(INavigationFeatures navigation, IEditorService editors, INotificationService notifications) : ICommandContributor
{
    public void Contribute(ICommandRegistry registry) =>
        registry.Add(new CommandDefinition("ini.countReferences", "Count References", "INI"), async _ =>
        {
            if (editors.ActiveEditor is not { } editor)
                return;

            var snapshot = editor.Document.Buffer.Current;
            var found = await navigation.GetReferencesAsync(editor.Document, snapshot, editor.CaretOffset, includeDeclaration: false, CancellationToken.None);
            notifications.Notify(NotificationKind.Info, $"{found.Count} references");
        });
}
```

## Keyboard hooks

Export an `IEditorKeyHook` to see keys in every editor before the editor handles them, such as for modal editing or recording macros.
`OnKeyDown` gets the editor and an `EditorKeyPress` (the key and its modifiers); `OnTextInput` gets the text a key typed. Return true to
handle it, so nothing after the hook sees it, not even the key bindings of commands.

```csharp title="ModalKeys.cs"
[Export(typeof(IEditorKeyHook))]
[Shared]
public sealed class ModalKeys : IEditorKeyHook
{
    private readonly ConditionalWeakTable<IEditorView, StrongBox<bool>> inserting = [];

    public int Priority => 100;

    public bool OnKeyDown(IEditorView editor, EditorKeyPress key)
    {
        var insert = inserting.GetOrCreateValue(editor);
        if (insert.Value)
        {
            if (key.Key != Key.Escape)
                return false;

            insert.Value = false;
            editor.CaretStyle = EditorCaretStyle.Block;
            return true;
        }

        switch (key.Key)
        {
            case Key.I:
                insert.Value = true;
                editor.CaretStyle = EditorCaretStyle.Line;
                break;
            case Key.H:
                editor.CaretOffset = Math.Max(0, editor.CaretOffset - 1);
                break;
            case Key.L:
                editor.CaretOffset = Math.Min(editor.Document.Buffer.Current.Length, editor.CaretOffset + 1);
                break;
        }

        return key.Modifiers == KeyModifiers.None;
    }

    public bool OnTextInput(IEditorView editor, string text) => !inserting.GetOrCreateValue(editor).Value;
}
```

The order keys go through is fixed:

1. An open completion list or signature help sees the keys it uses while it shows: the arrows, <Keys>Enter</Keys>, <Keys>Tab</Keys> and
   <Keys>Escape</Keys>.
2. The hooks, from the highest `Priority` to the lowest. Hooks with the same priority run in the order their plugins load.
3. The editor, then the key bindings of commands.

Hooks run on the UI thread for every key, so they must return at once. A hook that throws is skipped for that key and logged to the
**Plugins** channel of the **Output** panel, with its plugin. Users can turn a plugin's hooks off by adding its id to
`editor.disabledKeyHooks`.

## From language servers and analyzers

A [language server](./api.mdx#languages) gets these features from the requests it supports, with nothing more to write:

| Feature | Requests |
| --- | --- |
| Quick fixes and refactorings | `textDocument/codeAction`, `codeAction/resolve`, and `workspace/executeCommand` for actions and lenses that run a command |
| Rename | `textDocument/prepareRename`, `textDocument/rename` |
| Formatting | `textDocument/formatting`, `textDocument/rangeFormatting` |
| Inlay hints | `textDocument/inlayHint`, and `workspace/inlayHint/refresh` from the server |
| Code lens | `textDocument/codeLens`, `codeLens/resolve`, and `workspace/codeLens/refresh` from the server |
| Edits the server makes | `workspace/applyEdit`, applied like any workspace edit |
| References and implementations | `textDocument/references`, `textDocument/implementation` |
| Occurrence highlights | `textDocument/documentHighlight` |
| Symbols | `textDocument/documentSymbol`, as a tree or a flat list that Runesmith nests by range, and `workspace/symbol` of every running server |
| Folding | `textDocument/foldingRange`, and `workspace/foldingRange/refresh` from the server |
| Semantic tokens | `textDocument/semanticTokens/full` and `/range` with the server's legend, and `workspace/semanticTokens/refresh` from the server |
| Selection ranges | `textDocument/selectionRange` |
| Call and type hierarchies | `textDocument/prepareCallHierarchy`, `callHierarchy/incomingCalls` and `/outgoingCalls`, `textDocument/prepareTypeHierarchy`, `typeHierarchy/supertypes` and `/subtypes` |

A [language analyzer](./api.mdx#language-analyzers) implements any of these interfaces of `Runesmith.LanguageServices` next to
`ILanguageAnalyzer`; for references, symbols, folding, semantic tokens, selection ranges and hierarchies, its plugin exports the providers
above next to it:

| Interface | Members |
| --- | --- |
| `ICodeActionAnalyzer` | `CodeActionsAsync(document, span, includeRefactorings, cancellationToken)` returns `CodeActionEntry`s; `ResolveCodeActionAsync(entry, cancellationToken)` returns their `FileEdit`s. |
| `IRenameAnalyzer` | `PrepareRenameAsync(position, cancellationToken)` returns a `RenameSite`; `RenameAsync(position, newName, cancellationToken)` returns `FileEdit`s. |
| `IFormattingAnalyzer` | `FormatAsync(document, span, tabSize, insertSpaces, cancellationToken)` returns the changes of a document version, or of a span of it. |
| `IInlayHintAnalyzer` | `InlayHintsAsync(document, cancellationToken)` returns `InlayHintEntry`s: an offset, a text and whether it is a type that follows the text before it. They are asked for in the background lane, and again each time the analyzer finishes checking the document. |

A `FileEdit` is a path, the open document version its positions refer to (or null for the file on disk), and `PositionEdit`s by line and
column. Throw `AnalyzerRefusalException` with a message for the user, such as for a symbol that cannot be renamed. The C# analyzer implements
all four: the compiler's code fixes and refactorings, renamer and formatter, and hints for parameter names and `var` types.
