Runesmith is a code editor for Windows, Linux and macOS, built on .NET 10 and Avalonia. It opens a folder, shows its files and edits
them. It is the editor and the tools plugins build on: it knows no language by itself. Highlighting, completion, signature help, hover,
go to definition, problems, builds, runs and debugging for a language all come from the plugin of that language, and so do version
control and viewers for files that are not text.

## What this version does

This is the first version, the MVP:

- A docking workspace in light and dark. Panels and editors drag to any edge, into another group or out into a window of their own.
- An editor with typing aids such as closing brackets and keeping indentation, folding, and find and replace.
- A highlighting engine, and language services that turn the analyzers and language servers of plugins into completion, signature help,
  hover, go to definition and problems.
- Quick open, the command palette, find in files, the **Problems** and **Output** panels, a terminal, and building, running, debugging
  and testing with the plugins of your languages.
- Settings for you and for each folder, key bindings you can change, and a plugin hub to install plugins from.
