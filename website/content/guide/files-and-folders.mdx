---
title: Files and folders
description: Where Runesmith keeps your settings, key bindings, plugins, session, logs and caches, and how to keep them elsewhere.
---

Runesmith keeps three folders on your computer: a settings folder for what you set up yourself, a data folder for what it downloads and
manages, and a cache folder for what it can rebuild. Setting `RUNESMITH_HOME` moves all three, such as for a portable copy or a clean
profile.

## The folders

| Folder | Windows | Linux | macOS |
| --- | --- | --- | --- |
| Settings | `%APPDATA%\Runesmith` | `$XDG_CONFIG_HOME/runesmith`, by default `~/.config/runesmith` | `~/Library/Application Support/Runesmith` |
| Data | `%LOCALAPPDATA%\Runesmith` | `$XDG_DATA_HOME/runesmith`, by default `~/.local/share/runesmith` | `~/Library/Application Support/Runesmith` |
| Cache | `%LOCALAPPDATA%\Runesmith\Cache` | `$XDG_CACHE_HOME/runesmith`, by default `~/.cache/runesmith` | `~/Library/Caches/Runesmith` |

When the `RUNESMITH_HOME` environment variable is set, the settings folder is that folder, and the data and cache folders are `data` and
`cache` inside it.

## What is in them

| Path | What it holds |
| --- | --- |
| `settings.json` | Your [settings](./settings.mdx). |
| `keybindings.json` | Your [key bindings](./keyboard-shortcuts.mdx#keybindingsjson). |
| `editor-associations.json` | The [default editor](./open-with.mdx#change-the-default-editor) you chose for each kind of file. |
| `plugins/` | The [plugins](/plugins) you put there yourself, one folder each. |
| `state/layout.json` | The arrangement of the panels. |
| `state/window.json` | The window's size and place, and the last folder. |
| `state/recent.json` | The recent folders on the welcome page. |
| `state/sessions/` | The open files of each folder, one file per folder. |
| Data: `hub/plugins/` | The plugins you install from the [plugin hub](./plugins.mdx). Runesmith manages this folder and turns off a plugin whose files changed. |
| Data: `hub/` | The hub's installed state, the quarantine of plugins it blocked, its verified index and the plugin icons. |
| Data: `sdks/` | The [SDKs](./sdks.mdx) Runesmith installs. |
| Data: `plugin-data/` | Each plugin's own files, one folder per plugin, and `local/` for local copies of plugins Runesmith ships. |
| Cache: `logs/` | A file for each error Runesmith did not expect, such as `error-20261008-101829-221.log`. |
| Cache: `composition/` | The [composition cache](/developers/composition), which makes starting faster. |

Inside an open folder, `.runesmith/settings.json` holds the folder's own settings.

Deleting the cache folder is safe; Runesmith rebuilds what it needs. Deleting `state/` forgets the layout, the window and the sessions.
