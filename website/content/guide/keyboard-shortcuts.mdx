Every command can have keys, and you can change them all. This page lists the default bindings and shows how to change them. The keys the
editor handles itself, such as moving by words, are on [The editor](./editor.mdx#move-and-select).

On macOS, the defaults use <Keys>Cmd</Keys> where this page says <Keys>Ctrl</Keys>.

## Change a binding

<Steps>

1. Choose **Help › Keyboard Shortcuts**. The page lists every command by category, with its id and its keys; the search box finds commands
   by name, id or key.
2. Click the keys of a command, or **Add a binding** when it has none.
3. Type the keys, such as `Ctrl+Alt+Down`, and press <Keys>Enter</Keys>. Separate several with `|`. Leave the box empty to remove the
   binding.

</Steps>

Write modifiers first, then one key: `Ctrl`, `Shift`, `Alt` (or `Option`) and `Cmd` (or `Meta`), and keys such as `A`, `F5`, `Enter`,
`Space`, `Up`, `PageDown`, `/`, `=` or `,`.

## keybindings.json

Your bindings are saved in `keybindings.json`, next to your `settings.json`. It is a JSON object of command ids and keys; an empty value
removes a command's default binding:

```json title="keybindings.json"
{
  "edit.toggleComment": "Ctrl+Shift+7",
  "view.commandPalette": "Ctrl+Shift+P | F1",
  "file.exit": ""
}
```

Runesmith reads the file when it starts. The ids are on the **Keyboard Shortcuts** page beside each command.

## Keys in text boxes

While a text box has the focus, such as the find bar's, keys without <Keys>Ctrl</Keys>, <Keys>Alt</Keys> or <Keys>Cmd</Keys> type into the
box; function keys still run their commands. Undo, redo, cut, copy, paste and select all work on the text box or editor that has the focus.
