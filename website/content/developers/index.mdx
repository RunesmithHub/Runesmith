These pages are for people who work on Runesmith itself. To extend Runesmith without changing it, see [Plugins](/plugins).

Runesmith is a .NET 10 solution of small projects, each with one job: a text buffer, a language server client, the language services and the C# analyzer, the plugin API, the
composition of parts, the workspace, languages, the editor control, the shell and the executable. Its user interface comes from
[HammerUI](https://github.com/RunesmithHub/HammerUI), a UI library for Avalonia from the same author.
